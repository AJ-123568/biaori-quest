# 中也音色制作指南（全免费路线）

> 目标：用 1~2 分钟动画 cut，零成本得到"关掉名字也认得出"的中也音色，并能把任意新台词（中文/日语）合成语音接进游戏。
> 路线：素材清洗（本地 CPU）→ 零样本试水（本地 CPU，免训练）→ 不够像再上免费云 GPU 微调。

---

## 第一步：素材清洗（本地 CPU 即可）

### 方案 A：剪映（最省事，推荐先用这个）
1. 把中也 cut 导入剪映（电脑版/手机版都行）
2. 选中片段 →「音频」→「人声分离」（不同版本叫"分离人声/消除背景音"）
3. 导出**只含人声**的版本（wav 或高码率 mp3）

### 方案 B：UVR5（开源，效果上限更高）
1. 下载 UVR5（UVR - Ultimate Vocal Remover 5，GitHub 免费）
2. 模型选带 DeNoise 的（如 `UVR-DeNoise`）或 `1_HP-UVR`，只导出**人声（vocals）**轨
3. 动画 BGM 通常分离得很干净；有残留轻微音效可再跑一遍降噪

### 剪辑要求
- 目标：**≥60 秒**中也要**单独说话**的干净人声（有重叠人声/大笑盖过说话的段不要）
- 每句剪成 **1~10 秒**的小段，掐掉前后气口和尾音（后续训练标注就省事）
- **情绪配比**：大部分日常说话 + 若干炸毛/怒吼 + 若干低声认真。你的验收标准是"关掉名字认得出是中也"——那个"嗓门大吐槽"与"是。"的落差，素材里两面都要有
- 导出 **wav（16bit，44.1k/48k 均可）**；给 GPT-SoVITS 的参考音频和训练集一律用 wav，不要 mp3 二压。这段素材留着，第二、三步都要用

---

## 第二步：零样本试水（本地 CPU，免训练，先不花任何时间训练）

1. 下载 **GPT-SoVITS** 整合包：
   - 仓库：<https://github.com/RVC-Boss/GPT-SoVITS>
   - 整合包在 Releases 页：<https://github.com/RVC-Boss/GPT-SoVITS/releases> —— 选**最新的 v4 整合包**（文件名 `GPT-SoVITS-v4` 开头的 zip/7z），自带全部底模，解压即用，无需装环境
   - GitHub 直连被重置的话，挂上你的代理（127.0.0.1:7897）再下
2. 解压后运行 `go-webui.bat`。没有 N 卡它会自动走 CPU 模式——慢，但短句完全可用
3. 进推理界面（TTS 合成面板）：
   - **参考音频**：从清洗好的素材里挑一段 5~10 秒、最有"中也味"的（咬字清楚、情绪典型），转成 wav
   - **参考音频的文本**：填这段参考音频说的原话（日语照抄；面板有"无参考文本模式"的话可以开着让它自己转写，但手填更准）
   - **合成文本**：填想让中也说的台词，语言选对应项
   - 点合成。CPU 上一条短句十几秒到几十秒，等即可
4. **试听验收**：合 5~10 条不同情绪的台词（日常/吼/"是。"各来几条）
   - 够像 → 到此为止，第二、三步的整合包**留着**，它就是你以后的"配音工作室"
   - 不够像 → 记下哪里不像（音色像但腔调不像？还是整体不像？），进第三步微调

> 参考音频对零样本效果影响极大：换 2~3 段不同参考各试一次，挑最像的。

---

## 第三步（仅当零样本不够像）：免费云 GPU 微调

两条免费路线任选，**都是 0 元**：

### 路线 A：Google Colab（免费 T4 显卡，需要代理）
1. 官方仓库自带 Colab 笔记本（`ColabWebUI.ipynb`，仓库根目录能找到），逐格运行
2. 公网开启 WebUI 后，把清洗好的素材上传，走同样的流程：切分 → ASR 日语标注 → 人工校对 → 微调训练（SoVITS + GPT 各几分钟到半小时）
3. 训练完直接在云端 WebUI 批量合成全部台词，打包下载

### 路线 B：魔搭 ModelScope / 百度 AI Studio（国内直连，免翻墙）
- 两家都送免费 GPU 算力额度（需注册+实名），社区有现成的 GPT-SoVITS 部署笔记，搜"GPT-SoVITS 魔搭 / AI Studio"照抄即可

### 数据准备（云端和本地一致）
1. 素材**切分**：1~10 秒一段（面板内置切分工具）
2. **ASR 标注**：内置 FasterWhisper 选日语，自动生成"音频|文本"清单
3. **人工校对**：ASR 会写错拟声词/专有名词，把错的改掉（这一步决定合成质量，值得花 20 分钟）
4. **微调**：默认参数起步，显存/时长报错再调小批量
5. **批量合成**：推理面板的批量合成功能，按台词清单一次跑完，打包 wav

> 1~2 分钟素材是微调的下限。训完仍不满意 → 补素材（BEAST 剧场版、游戏台词）到 5~10 分钟再训一轮，相似度会明显上去。

## 第四步：把语音接进游戏（配合 config/companion.json）

### 加新台词的固定流程（以后都这样，不用改代码）
1. 在 `config/companion.json` 的 `lines` 里加一条：写 `text`（中文或日语）、`lang`、想触发的 `event`
2. 想要中也本音 → 用你的整合包（零样本或你微调好的模型）合成这条的 wav，命名后放进 `audio/companion/`，在条目里填 `audio` 路径
3. 不想配音的条目 → 不填 `audio`，游戏回落到系统 TTS 念出来（`lang` 定语种，`voice` 可指定系统音色名的一部分，如 `Keita`、`晓伊`）

### 命名建议
`事件-序号.wav`，如 `correct-01.wav`、`combo5-01.wav`、`clear3-01.wav`。同一事件放多条，游戏随机抽一条才不会腻。

### 中文台词
微调后的模型支持跨语言推理，日语素材练出来的音色也能说中文（略带口音）。先合成一条试听，接受度自己把握。

---

## 常见问题

- **音色不像**：换参考音频再试（影响最大）→ 补素材量 → 微调
- **念错专有名词**：日语台词把汉字读音写成假名再合成（如「汚濁」→「おだく」）
- **爆音/气口怪**：换一段更干净的参考音频；参考音频质量 > 一切参数
- **CPU 太慢**：只影响生成速度不影响音质，挂机即可；或临时走免费云
- **合成整段哑掉**：检查参考音频是否静音/文本语言选项是否选对
