# 中也音色——全免费计划（含自定义台词/语言/语音）

## 语音管线（不变，三档全免费逐级升级）
1. **素材清洗**（本地 CPU）：剪映人声分离或 UVR5 去 BGM，凑 ≥60 秒干净人声，覆盖日常/炸毛/低声三档
2. **零样本试水**（本地 CPU）：GPT-SoVITS V4 整合包 CPU 模式，10~20 秒参考音频直接合成试听；按"关掉名字认得出"验收
3. **免费云微调**（仅不够像时）：Colab 免费 T4（有代理，官方自带笔记本）或魔搭/百度 AI Studio 免费算力；微调后云上批量合成

## 自定义体系（本次新增，写进 P3 设计）
- `config/companion.json` 全开放：每条 `{text, lang: "zh"|"ja", event?, audio?, voice?}`，增删改条目即生效，无需碰代码
- **加新台词的固定流程**：写台词（中日皆可）→ 本地整合包合成 wav（零样本几十秒一条；微调后用你的模型；中文走跨语言推理，略有口音）→ wav 放 `audio/companion/` → config 加一行
- 无 audio 的条目回落 Web Speech API：lang 定语种、voice 可指定系统音色——任意文本即时说，但非中也本音
- 可选加一个游戏内"让中也说一句"输入框（选语言→系统 TTS 即时说），要就在 P3 里带上，不要就只走 config
